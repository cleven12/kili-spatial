# Code of Conduct

We want KiliSpatial to be a friendly, harassment-free project for everyone, whatever their background, experience or language.

**Expected:** be respectful and constructive, assume good intent, accept feedback graciously, and focus on what is best for people who use the project.

**Not acceptable:** harassment, insults, discrimination, personal attacks, publishing others' private information, or any conduct that would be inappropriate in a professional setting.

Maintainers may edit or remove comments, issues and contributions that break these rules, and may ban people who repeatedly do so. To report a problem, contact the maintainer privately through the GitHub profile linked from the repository.

This text is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
