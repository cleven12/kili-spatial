# Security policy

KiliSpatial is a static web app with no accounts and no server-side code, but problems can still exist (for example in the embed `postMessage` bridge or the file import).

**Reporting a vulnerability:** please do not open a public issue. Use GitHub's private reporting: the repository's **Security** tab, then **Report a vulnerability**. You will get a reply as soon as possible.

Safety information about the routes (trail errors, wrong elevations) is not a security issue. Please open a normal issue for that, and remember that the app is not for navigation.
